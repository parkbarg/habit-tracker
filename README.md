# Habit Tracker

シンプルな習慣進捗管理Webアプリケーションです。

毎日の日課を登録し、その日の達成状況をチェックすることで、継続状況や達成率を確認できます。

MVPでは機能を最小限に絞り、すべてを1画面で操作できる構成にします。

## 目的

日々の習慣を簡単に記録し、自分がどれくらい継続できているかを把握できるようにすることを目的としています。

まずは機能を増やさず、自分自身が毎日使える最小構成のアプリケーションを完成させます。

## 機能要件

### 1. 日課を登録できる

日課名を入力して、新しい日課を登録できます。

例:

* 7時に起きる
* スマホを禁止ボックスに入れる
* 勉強する

### 2. 日課の達成状況を登録できる

選択している日付の日課を一覧表示し、チェックボックスで達成状況を登録できます。

* チェックあり: 達成
* チェックなし: 未達成
* 日付が変わると、その日の達成状況は新しく管理される
* 過去の記録は保持する

### 3. 進捗を表示できる

日課の記録から以下の情報を表示します。

* 連続達成数
* 達成率
* 達成数
* 失敗数

### 4. 過去の達成状況を登録・修正できる

画面上部の日付を変更することで、過去の日課の達成状況を確認・修正できます。

これにより、その日に記録し忘れた場合でも後から登録できます。

## 画面構成

MVPでは画面遷移を作らず、すべての機能を1画面にまとめます。

```text
┌────────────────────────────────────────────────────────────┐
│ Habit Tracker                         < 2026/09/03 >       │
├──────────────────────────────┬─────────────────────────────┤
│ 今日の日課                   │ 進捗                        │
│                              │                             │
│ ☑ 7時に起きる               │ 達成率        75%           │
│ ☐ スマホを箱に入れる        │ 達成数        15            │
│ ☑ 勉強する                   │ 失敗数        5             │
│ ☐ 23:30までに寝る           │ 連続達成数    4日           │
│                              │                             │
│                              ├─────────────────────────────┤
│                              │ 日課を追加                  │
│                              │                             │
│                              │ [ 日課名を入力           ] │
│                              │                             │
│                              │ [ ＋ 追加 ]                │
└──────────────────────────────┴─────────────────────────────┘
```

### 日付変更

画面上部の日付を変更すると、その日の記録を表示します。

```text
< 2026/09/03 >
```

過去の日付を選択すれば、その日のチェック状態を確認・変更できます。

### 日課一覧

登録済みの日課をチェックボックス付きで表示します。

```text
☑ 7時に起きる
☐ スマホを禁止ボックスに入れる
☑ 勉強する
```

チェック状態を変更すると、その日の日課記録を更新します。

### 進捗

同じ画面上に進捗を表示します。

```text
達成率      75%
達成数      15
失敗数      5
連続達成数  4日
```

### 日課追加

同じ画面上から新しい日課を追加できます。

```text
[ 日課名を入力 ]

[ ＋ 追加 ]
```

## データ構造

MVPでは2テーブルのみを使用します。

### habits

日課そのものを管理します。

| カラム  | 内容   |
| ---- | ---- |
| id   | 日課ID |
| name | 日課名  |

### habit_records

日付ごとの達成状況を管理します。

| カラム       | 内容    |
| --------- | ----- |
| id        | 記録ID  |
| habit_id  | 日課ID  |
| date      | 対象日   |
| completed | 達成したか |

`habit_id` と `date` の組み合わせで、その日の日課の達成状況を管理します。

例:

```text
habit_id: 1
date: 2026-09-03
completed: true
```

## 技術構成

予定している構成:

* Frontend: Vue + TypeScript
* Backend: FastAPI
* Database: SQLite または PostgreSQL
* Container: Docker / Docker Compose
* Client: Windows上のWebブラウザ

## MVPでは実装しないもの

最初のバージョンでは以下の機能は実装しません。

* ユーザー登録・ログイン
* 通知
* 曜日ごとの日課設定
* 平日・休日ごとの日課設定
* カテゴリ
* 目標時刻
* ゲーミフィケーション
* SNS機能
* 複雑な分析機能
* 複数画面への画面遷移

必要になったものだけ後から追加します。

## MVPの完成条件

以下ができれば最初のバージョンは完成とします。

1. 日課を追加できる
2. 選択した日付の日課を一覧表示できる
3. チェックボックスで達成状況を変更できる
4. ページを再読み込みしても記録が残る
5. 翌日は未チェックの状態から始まる
6. 過去の日付の記録を変更できる
7. 達成数を確認できる
8. 失敗数を確認できる
9. 達成率を確認できる
10. 連続達成数を確認できる

## 開発方針

機能を増やすことよりも、まず自分自身が毎日使える状態まで完成させることを優先します。

MVPでは、

```text
開く
↓
チェックする
↓
進捗を見る
↓
閉じる
```

という操作を短時間で行えることを重視します。
