# Habit Tracker - 機能要件・画面仕様

MVPで実装するユーザー機能と画面挙動を定義する。

**Version 1.0 | 2026-10-04**

## 1. プロダクトの目的

自分が各目標をどの程度継続できているかを月単位で把握し、どの日に達成・一部達成・未達だったかを振り返れる習慣トラッカーを作る。

- 対象はPCブラウザ。MVPは自分専用で認証なし。
- すべての目標は毎日が対象。月の日数を分母にする。
- 継続状況は「○・△・×・空白」の4状態で管理する。
- 累計・年間分析・曜日指定・実施頻度設定はMVP対象外。

## 2. 画面構成

### 2.1 トップ画面（目標一覧）

- ヘッダーにアプリ名「Habit Tracker」を表示する。
- 上部に `< 2026年10月 >` 形式の月切り替えを配置し、左右矢印で1か月ずつ移動する。過去・未来とも無制限。
- 選択中の年月はURLクエリ（`year`, `month`）で保持する。
- 右上付近に「登録」ボタンを置き、目標登録モーダルを開く。
- 目標一覧は登録順で表示する。目標が0件でも空の表を表示する。
- 表の列順は「目標名 → ○ → △ → × → ⋮」。
- ○・△・×は「件数 / その月の日数」で表示する。例：`18 / 31`。空白日は件数に含めない。
- 行をクリックすると、その目標のダッシュボードへ遷移する。選択中の年月は引き継ぐ。
- `⋮` メニューから「編集」「削除」を実行できる。

| 目標名 | ○ | △ | × | 操作 |
| --- | ---: | ---: | ---: | :---: |
| SC勉強 | 18 / 31 | 4 / 31 | 3 / 31 | ⋮ |
| 筋トレ | 12 / 31 | 6 / 31 | 7 / 31 | ⋮ |

### 2.2 目標ダッシュボード

- ヘッダーは「Habit Tracker / 目標名」。Habit Trackerをクリックするとトップ画面へ戻る。専用の戻るボタンは置かない。
- トップ画面と同じ左右矢印式の月切り替えを置く。
- 上部に○・△・×の3枚のカードを横一列に表示する。
- ○カードは緑系、△カードは黄系、×カードは赤系。各カードは「件数 / 月の日数」。
- 累計値は表示しない。月ごとの結果のみ表示する。

### 2.3 月間カレンダー

- 月曜始まり。曜日順は「月 火 水 木 金 土 日」。
- 当月の日付だけ表示し、前月・翌月の日付は表示しない。
- 常に6週間分の高さを確保する。余ったセルは空白・クリック不可。
- 各セルには薄い枠線を付ける。日付数字のみ表示する。
- 今日の日付の特別な強調表示はしない。
- 土日・祝日などによる特別な表示はしない。
- ○はセル全体を薄い緑、△は薄い黄、×は薄い赤、空白は白で表示する。セル内に○△×の文字やバッジは表示しない。
- セル全体をクリック可能にする。未来日を含む任意の日付をいつでも編集できる。

### 2.4 日付編集モーダル

- 選択肢は「○ / △ / × / 空白」。
- 選択しただけでは保存せず、「保存」ボタンで確定する。
- 「キャンセル」で変更せず閉じる。
- 既存の状態はいつでも別状態へ変更できる。
- 空白にするとその日の習慣記録自体を削除する。

## 3. 目標管理

- 目標登録時の入力項目は「目標名」のみ。
- 目標名は1〜30文字。前後の空白を除去して保存・判定する。
- 同名目標は大文字・小文字を区別せず重複禁止。
- 登録・編集はモーダルで行う。
- 削除時は確認ダイアログを表示し、確定後は完全削除する。削除した目標に紐づく記録も削除する。
- 目標を登録した時期より前の月でも、その目標を表示・編集できる。

## 4. 通知・エラー表示

- 成功・エラーの両方をトースト通知で表示する。
- トースト位置は画面右下。
- 数秒後に自動で消え、手動でも閉じられる。
- 例：目標を登録しました／変更を保存しました／目標を削除しました／記録を保存しました／保存に失敗しました。

## 5. UIテーマ

- ライトテーマのみ。白〜薄いグレーをベースにする。
- 状態色は○=緑系、△=黄系、×=赤系で統一する。
- スマートフォン向け最適化はMVP対象外。PCレイアウトを優先する。

## 6. MVP対象外

- ユーザー登録・ログイン（将来追加予定）
- 祝日・有給・休み・午前休・午後休などの日種別管理
- 日本の祝日の自動取得
- 継続率の単一パーセント表示や△の重み付け計算
- 全期間累計・年間分析・グラフ
- 目標のドラッグ＆ドロップ並び替え
- 曜日指定・週N回などの実施スケジュール
